# MyRTS — Лунная колония

2D RTS о разработке ресурсов на Луне. Частная колония, кредит,
добыча гелия-3, производственные цепочки, научные исследования
через решение математических задач.

## 📖 Сюжет

См. [STORY.md](STORY.md)

## 🚀 Как запустить

1. Установить Python 3.9+
2. Установить зависимости:

pip install pygame numpy

3. Запустить.


## 🎮 Управление

- **ЛКМ** — выделить юнита / рамка выделения группы.
- **Shift + ЛКМ** — добавить к выделению.
- **ПКМ** — приказ идти.
- **Стрелки / WASD** — прокрутка камеры.
- **Мышь у края экрана** — автопрокрутка.
- **Клик по миникарте** — переместить камеру.
- **ESC** — выход.
